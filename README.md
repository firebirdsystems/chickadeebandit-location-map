# Location Map

A [Chickadee Bandit](https://chickadeebandit.com/app-library/location-map) app.

Shows where family members are on an interactive map. Widget-only — pin it to your dashboard.

## Features

- Interactive map of family member locations.
- Home-screen widget only, no separate screen.
- Available to every member, not just adults — it shows exactly what the Location page already shows.
- Uses the hub's built-in location sharing.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-location-map/releases/latest/download/bundle.json
```
